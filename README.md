# 🏙️ CityGuide

Android-приложение — путеводитель по интересным местам городов России. Пользователь выбирает город, затем категорию, смотрит список мест с описанием и фотографией и может добавлять понравившиеся места в избранное.

## 📱 Возможности

- **Выбор города** — Москва, Санкт-Петербург, Сыктывкар, с поиском по названию
- **8 категорий мест:**
  - 🌳 Парки
  - 🏛️ Культура
  - 🏃 Активный отдых
  - ⚡ Новые ощущения
  - 🦒 Флора и фауна
  - 🖼️ Выставки
  - 🎮 Игры
  - 🎨 Искусство
- **Карточка места** — название, адрес, описание и фотография
- **Избранное** — места можно отмечать звёздочкой, они сохраняются в локальной базе данных
- **Нижняя панель навигации** — быстрый переход к выбору города и к избранному

| | |

## 🗄️ База данных

Таблица `places`:

| Поле | Тип | Описание |
|---|---|---|
| `_id` | INTEGER | первичный ключ |
| `name` | TEXT | название места |
| `city` | TEXT | город |
| `category` | TEXT | категория |
| `description` | TEXT | адрес и описание |
| `imageName` | TEXT | имя картинки из `drawable` |
| `isFavorite` | INTEGER | 1 — в избранном, 0 — нет |

База заполняется при первом запуске приложения в `DBHelper.onCreate()`.

## 🚀 Запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/zxcharm/CityGuide.git
   ```
2. Открыть папку проекта в **Android Studio**
3. Дождаться синхронизации Gradle
4. Запустить на эмуляторе или устройстве с Android 7.0+ (кнопка ▶ **Run**)

## ➕ Как добавить новое место

В `DBHelper.java` в методе `onCreate()` добавить вызов:

```java
insertPlace(db, "Название", "Город", "категория", "Адрес\nОписание", "имя_картинки");
```

Положить картинку в `res/drawable/` и увеличить `DATABASE_VERSION`, чтобы база пересоздалась.
